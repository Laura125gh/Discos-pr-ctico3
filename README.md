🎵 Proyecto de Música

📌 Descripción

Este proyecto consiste en una aplicación web de música desarrollada con React, en la que se muestran diferentes discos de artistas reconocidos. Cada disco cuenta con una imagen, el nombre del artista y una descripción.

El objetivo es practicar los conocimientos adquiridos en el desarrollo web, utilizando componentes y JavaScript para organizar y mostrar la información de manera dinámica.

🛠️ Tecnologías utilizadas

HTML: estructura de la aplicación.

CSS: estilos y diseño visual.

JavaScript: manejo de datos y lógica.

React: creación de componentes e interfaz de usuario.

Vite: herramienta para ejecutar y desarrollar el proyecto.

⚙️ Funcionalidades

Visualización de discos musicales.

Imágenes de los discos mediante enlaces.

Descripción de cada artista o álbum.

Visualización de precios.

Organización de la información para facilitar su presentación.
